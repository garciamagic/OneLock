Secret reveal

The code appears as the red notification numbers on the dock icons, 2 digits per icon, left to right. A pair starting with 0 shows one digit (05 → 5); 00 shows no badge. With no code saved, the dock shows its normal badges.

How to perform

  1. Swipe up on the lock screen to bring up the keypad. (Tapping Cancel with nothing typed goes back.)
  2. Hold any digit 1–9 for 2s to set how many dots there are.
  3. Type a code — it shakes and fails, like a real phone. It’s secretly remembered.
  4. Double-tap Cancel. The passcode dots blink once: any code now unlocks. (Double-tap again to turn it off — they blink longer.)
  5. Hand it over. Any code they type opens the home screen.
  6. Read the code from the dock badges, left to right, 2 digits each.
  7. Double-tap anywhere on a home page to show the next remembered code in the badges (it loops back around).
  8. To lock again and reset: pull down from the top edge of a home screen (the lock screen slides down), or hold anywhere for 2s.
